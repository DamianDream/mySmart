# mySender Tools 🚀

Powerful sidebar extension for `console.smartsender.com` to manage your project's data with peak efficiency.

---

## ⚡ Variables Tab
Manage project variables with total control.
- **Smart Search**: Find variables by name or ID, supports comma-separated bulk entries.
- **Inline Editing**: Modify variable values directly with real-time status feedback.
- **Edit History**: View and restore the last 5 values for any variable at any time.
- **Powerful Presets**: Group variables for recurring tasks. Load, configure, or duplicate them instantly.
- **Slide-Out Panels**: Manage History and Presets in seamless side-panels that optimize your workspace.

## 🏷 Tags Tab
Discover and track tags across your project.
- **Rapid Lookup**: Instant search by partial or exact tag names.
- **ID Discovery**: Identify the unique IDs needed for SmartSender automations and flows.
- **Quick Actions**: One-click ID copying to keep your workflow moving.

## 👤 Contacts Tab
Comprehensive management for your user base.
- **Universal Search**: Find any contact by User ID, Email, or Name.
- **Detailed Profiles**: Access comprehensive contact data in a dedicated slide-out window.
- **Inline Editing**: Update contact variables directly from the profile with real-time API sync.
- **Favorites System**: Star important contacts for immediate access via the Favorites panel.
- **Flexible UI**: Switch between compact cards for high-density browsing or detailed views.

## 🌍 Universal Accessibility
- **Works Everywhere**: Use the tool on any website (Google, CRMs, etc.) to lookup and manage your SmartSender data.
- **Project Switcher**: Rapidly switch between your saved projects from the footer or settings.
- **Smart Detection**: Automatically syncs with the project identifier (e.g., `newlook-73200`) from the SmartSender dashboard URL.
- **Auto/Manual Modes**: Toggle between following the dashboard's project or locking to a manual choice.

## 🎨 Professional Experience
- **Resizable Sidebar**: An elastic workspace that adapts to your screen and workflow.
- **Unified Navigation**: A clean burger menu to switch between all functional areas.
- **Fluid Transitions**: All secondary panels slide behind the sidebar for a sleek, modern feel.
- **Custom Branding**: Fully themeable (Dark/Light) with adjustable typography scaling.

---

## 🛠 Installation
1. Navigate to `chrome://extensions/` in Google Chrome.
2. Enable **Developer mode** in the top-right corner.
3. Click **Load unpacked** and select the extension directory.
4. Refresh `console.smartsender.com` and click the extension icon.
