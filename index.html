Интерфейс и разделы

Полный контроль над SmartSender в одном сайдбаре

Наглядный обзор всех ключевых рабочих пространств mySmart: контакты, запуск событий, управление переменными, тегами и настройками проектов.

01

Управление контактами

Мгновенный поиск подписчиков по ID, имени, телефону или email. Разворачивание карточки контакта с приоритетными переменными, инлайн-управлением тегами (удаление по ×, прикрепление по + Tag) и прямым вызовом Fire Event.

✓ Интерактивные чипы тегов с мгновенным удалением и прикреплением
✓ Приоритетные переменные (Priority Variables) в топе профиля
✓ Открытие в отдельном всплывающем окне по центру экрана
Contacts Tag Management Popup Window
02

Модуль событий (Fire Event)

Запуск любых триггерных событий SmartSender по официальному API за доли секунды. Незаменимо для тестирования воронок, списания баллов в программах лояльности, имитации вебхуков и ручного перезапуска сценариев.

✓ Быстрый ввод Contact ID и названия события (Event Name)
✓ История недавних событий с быстрым повтором в один клик
✓ Очистка истории и подробный статус ответа сервера
POST /fire Event History Automation Testing
03

Редактор переменных & Экспорт / Импорт

Поиск, редактирование и копирование синтаксиса {{variable}} прямо во время работы. Функция Project Variables Transfer позволяет выгружать определения переменных в JSON и импортировать их в новые проекты с автоматическим diff-превью и защитой от перезаписи.

✓ Прямое редактирование значений переменных (PUT) с историей отката
✓ Пользовательские пресеты (Presets) для группировки переменных
✓ Экспорт и импорт переменных между проектами с diff-анализом
Variables Diff Preview Transfer JSON
04

Менеджер тегов & Избранное

Каталог всех тегов вашего проекта с мгновенным поиском, копированием Tag ID для внешних интеграций и боков воронок, а также быстрым добавлением в раздел избранных тегов (Favorites).

✓ Мгновенный поиск тега по названию с пагинацией
✓ Копирование Tag ID в один клик с визуальным подтверждением
✓ Список избранных тегов (Favorites) для быстрого доступа
Tags Catalog Favorites Tag ID Copy
05

Мультипроектность & Настройки

Переключайтесь между проектами SmartSender без повторной авторизации. Настраивайте умное кэширование ответов API, автопоиск при вводе и цветовую схему (выбор цвета фона, кнопок и текста или готовые пресеты Dark, Light, Black & White, White & Black).

✓ Auto/Manual распознавание проекта по URL в SmartSender
✓ Умный локальный API-кэш для мгновенной скорости и экономии лимитов
✓ Полный бэкап и восстановление пресетов расширения в один файл

Функциональные возможности

Полный обзор инструментов и модулей mySmart для ускорения ежедневной работы в SmartSender.

Модуль событий (Fire Event)

Запуск триггерных событий для контактов в один клик. Идеально для тестирования воронок, списания баллов, интеграционных вебхуков и ручного перезапуска логики сценариев.

  • Отдельная вкладка меню "Events"
  • Кнопка вызова прямо в карточке контакта
  • История последних запусков с кнопкой повтора
  • Очистка истории (Clear History)

Управление контактами

Интеллектуальный поиск по всей базе подписчиков. Моментальное открытие карточки с отображением мессенджера, статуса, телефона и пользовательских параметров.

  • Поиск по имени, номеру и Contact ID
  • Центрированное всплывающее окно (Popup Window)
  • Очередь вызова карточек без подвисаний
  • Прямой переход в SmartSender Console

Редактор переменных

Просмотр и изменение значений переменных контакта, а также экспорт и импорт определений переменных между проектами с diff-анализом.

  • Мгновенное копирование синтаксиса {{variable}}
  • Экспорт и импорт переменных (Project Variables Transfer)
  • Автоматический расчёт диффа (+new / exist) при импорте
  • История локальных изменений и верификация записи

Менеджер тегов

Управление тегами контакта прямо в сайдбаре и поп-ап окне: снятие тега в один клик (×), прикрепление (+ Tag) и создание новых тегов на лету.

  • Добавление и снятие тегов контакта на лету
  • Создание нового тега проекта из строки поиска
  • Фильтрация контактов по тегам
  • Синхронизация с API за миллисекунды

Мультипроектность и пресеты

Работайте с несколькими проектами SmartSender без постоянного повторного ввода API-токенов. Удобный перенос переменных и бэкап настроек.

  • Изолированные токены проектов
  • Автоматическое переключение контекста
  • Быстрый перенос переменных между ботами
  • Безопасное хранилище chrome.storage

Приватность и безопасность

Все API-запросы выполняются строго напрямую между вашим браузером и официальным сервером SmartSender. Ваши токены и данные подписчиков никогда не передаются третьим лицам.

  • Прямые HTTPS-запросы к api.smartsender.com
  • Отсутствие сторонних трекеров и аналитики
  • Полная поддержка Manifest V3 Content Security Policy
  • Локальный кэш без утечек памяти

Журнал действий & Диагностика (Logs)

Сквозной аудит всех запросов к SmartSender REST API в режиме реального времени. Точная расшифровка ошибок валидации 422 с перечислением проблемных параметров.

  • Логирование запросов, статусов и тел ответов
  • Детализированный вывод ошибок валидации 422
  • Фильтрация и очистка истории в один клик
  • Быстрое обнаружение проблем с авторизацией

Всплывающее окно контактов (Popup)

Автономное окно с поддержкой нескольких вкладок для параллельной работы с контактами. Открывается строго по центру экрана, не загораживая рабочую область.

  • Многовкладочный интерфейс (Multi-tab Contact View)
  • Эргономичное центрирование по экрану браузера
  • Полная поддержка инлайн-редактирования и тегов
  • Кнопка принудительного обновления данных

Кастомизация & Smart Cache

Полная свобода оформления: выберите 3 ключевых цвета (фон, кнопки, текст) с помощью пикера или нажмите один из готовых пресетов — Dark, Light, Black & White, White & Black. Настраиваемый кэш API и автопоиск при вводе.

  • Выбор цвета фона, кнопок и текста — по отдельности
  • 4 готовых пресета + режим Custom с палитрой быстрых свотчей
  • Умное кэширование повторных запросов на 5 минут
  • Поиск на лету (Search as you type / Auto Fetch)

Установка в Google Chrome

Пошаговая инструкция по ручной установке расширения в режиме разработчика за 60 секунд.

1

Скачайте и распакуйте архив

Загрузите готовый пакет расширения mysmart-chrome.zip и распакуйте его в любую удобную папку на вашем компьютере (например, в Загрузки или Документы). Не удаляйте распакованную папку после установки.

Скачать mysmart-chrome.zip
2

Откройте страницу расширений Chrome

Вставьте адрес chrome://extensions в адресную строку вашего браузера Google Chrome и нажмите Enter.

chrome://extensions
3

Включите «Режим разработчика»

В правом верхнем углу страницы расширений переведите переключатель «Режим разработчика» (Developer mode) в активное положение. В панели инструментов появятся дополнительные кнопки управления.

4

Загрузите распакованное расширение

Нажмите на кнопку «Загрузить распакованное расширение» (Load unpacked) в левом верхнем углу и выберите распакованную папку (где находится файл manifest.json).

💡 Совет: Нажмите на значок пазла в правом верхнем углу Chrome и закрепите (Pin) иконку mySmart, чтобы боковая панель открывалась по клику или горячим клавишам.

Часто задаваемые вопросы

Безопасно ли устанавливать расширение вручную?
Да, абсолютно. Расширение mySmart не содержит скомпилированного бинарного кода, все исходные скрипты открыты для аудита, а сетевые запросы отправляются напрямую в SmartSender без передачи ваших токенов на сторонние серверы.
Как обновлять mySmart до новых версий?
При выходе новой версии скачайте свежий архив, замените файлы в вашей папке расширения и нажмите кнопку «Обновить» (иконка круговой стрелки) на карточке расширения в chrome://extensions.
Где взять API токен SmartSender?
Перейдите в личный кабинет SmartSender в раздел «Настройки» → «Токены API», создайте новый токен с правами на контакты и переменные, после чего вставьте его в настройки mySmart.
